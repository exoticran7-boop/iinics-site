Magnetic Absolute Rotary Encoder

자기장 변화로 절대위치를 읽는 마그네틱 앱솔루트 엔코더. 광학부품을 사용하지 않아 내구성이 매우 우수하며, 분진 · 오일 등 열악한 환경에서도 높은 신뢰성을 제공합니다. 샤프트 타입(Ø40 · Ø50mm) 단일 구성입니다.

Key Features · 제품 특징

FEATURE 01
앱솔루트 — 전원 인가 즉시 절대위치
Absolute Position Detection
각 회전각마다 고유한 코드를 출력하는 앱솔루트 방식입니다. 전원을 켜는 순간 현재 위치를 바로 알 수 있어 원점 복귀 동작이 필요 없고, 정전 후에도 위치를 잃지 않습니다.
Every angle outputs a unique code — the position is known the moment power is applied. No homing sequence, no position loss after a power interruption.
FEATURE 02
광학부품 제로 — 압도적 내구성
No Optical Parts · High Durability
광학 디스크 · LED 없이 자기 센서만으로 동작해 내구성이 매우 우수합니다. 분진 · 오일 · 진동이 많은 열악한 산업 현장에서도 안정적으로 동작합니다.
No optical disk or LED — magnetic sensing only, for outstanding durability and stable operation in dusty, oily, high-vibration environments.
FEATURE 03
Binary / Gray 코드 선택
Binary / Gray Code
출력 코드를 Binary와 Gray 중 선택합니다. Gray 코드는 하나의 비트만 변하면서 값이 바뀌기 때문에 비트 딜레이로 인한 순간 오독을 원천적으로 방지합니다. 회전방향(F: 시계 증가 / R: 반시계 증가)도 선택 가능합니다.
Gray code changes only one bit at a time, eliminating misreads from bit delays. Count direction is selectable (F: CW up / R: CCW up). BINARY GRAY F / R
FEATURE 04
2가지 출력 — 병렬 NPN / SSI
Parallel NPN / SSI Line Driver
병렬 NPN 모델은 2⁰~2⁹ 10개 신호선으로 분해능 8~1024를 직접 출력하고, SSI 모델은 라인드라이버 동기 시리얼 통신 (클럭 50k~500kHz)으로 최대 4096 분해능을 전송합니다.
Parallel NPN outputs 10 bit lines (res. 8–1024); SSI streams up to 4096 P/R over a synchronous line-driver interface at 50k–500 kHz.
FEATURE 05
SSI 멀티턴 — 16,384회전 카운트
16,384-Rev Multi-turn (SSI)
SSI 모델은 단회전 각도에 더해 회전수를 14bit(16,384회전)로 누적 카운트합니다. 긴 이송축 · 다회전 기구의 위치를 하나의 데이터로 관리할 수 있습니다. (전원 차단 시 다회전 카운트는 0으로 초기화됩니다.)
SSI adds a 14-bit revolution counter (16,384 turns) on top of the single-turn angle. Note: the multi-turn count resets to 0 at power off.
FEATURE 06
±1LSB 히스테리시스 · CE
±1 LSB Hysteresis · Rugged · CE
경계각에서의 값 떨림을 ±1LSB 히스테리시스로 억제해 안정된 코드를 출력합니다. 내충격 50G · 내진동 5G · IP50, 알루미늄 / PA66-GF30 바디, 커플링 동봉, CE 인증.
±1 LSB hysteresis suppresses code flicker at boundaries. 50G shock, 5G vibration, IP50, aluminum or PA66-GF30 body, coupling included. CE certified.

Technology · 감지 원리

Magnetic Absolute Sensing

전원을 켜는 순간, 위치를 안다

Position Known the Moment Power Is On

회전축에 장착된 자석이 돌면 자기 센서가 자기장의 방향을 읽어 현재 각도를 계산합니다. 모든 각도가 고유한 디지털 코드에 대응하므로, 펄스를 세지 않고도 지금 이 순간의 절대위치를 바로 출력합니다.

As the magnet on the shaft rotates, the magnetic sensor reads the field direction and computes the current angle. Every angle maps to a unique digital code, so the absolute position is output instantly — no pulse counting required.

  • 비접촉 자기 감지 — 자석과 센서가 닿지 않아 마모가 없고, 광학부품이 없어 오염에 강합니다. Non-contact magnetic sensing — magnet and sensor never touch, and with no optics it resists contamination.
  • 각도 = 고유 코드 — 최대 4096등분(12bit)의 각 위치가 서로 다른 코드로 출력됩니다. Angle = unique code — up to 4,096 positions (12 bit), each with its own code.
  • Gray 코드 옵션 — 인접 각도 간 1비트만 변해 경계에서의 오독을 방지합니다. Gray code option — only one bit changes between adjacent angles, preventing misreads at boundaries.
  • SSI 멀티턴 — 회전수 14bit + 단회전 각도를 한 번의 시리얼 프레임으로 전송합니다. SSI multi-turn — 14-bit turn count plus single-turn angle in a single serial frame.
