Programmable High-Speed Counter Timer

DIN-Rail 취부형 엔코더(×4 체배) 고속 카운터/타이머. 최고 100kcps의 초고속 펄스를 정밀 계수하며, 카운터와 타이머 · BATCH 계수 · 프리스케일 기능을 한 대에 담은 자동화 제어용 복합 카운터입니다.

A DIN-rail programmable high-speed counter/timer with x4 encoder multiplication. Counts pulses up to 100 kcps and combines counter, timer, batch counting and prescale in one unit.

Key Features · 제품 특징

FEATURE 01
최고 100kcps 초고속 계수
Ultra High-Speed Counting
계수속도를 1cps · 30cps · 1kcps · 10kcps로 선택할 수 있고, ENC(엔코더) 모드에서는 최고 100kcps — 최소 신호폭 0.005ms의 초고속 펄스까지 정밀하게 계수합니다.
Selectable counting speeds of 1, 30, 1k and 10k cps, and up to 100 kcps in encoder mode — capturing pulses as narrow as 0.005 ms.
FEATURE 02
카운터 · 타이머 겸용 1대 통합
Counter + Timer in One Unit
설정 하나로 카운터와 타이머를 전환합니다. 카운터 입력모드 14종(UP · DOWN · UP/DOWN · ENC), 카운터 출력모드 8종, 타이머 출력모드 10종(OND · FLK · INT 등)으로 장비에 맞는 동작을 자유롭게 구성합니다.
One setting switches between counter and timer: 14 counter input modes, 8 counter output modes and 10 timer output modes cover virtually any control sequence.
FEATURE 03
프리스케일 — 펄스를 길이로
Prescale Function (0.001–999.999)
1펄스당 실제 변화하는 길이 · 위치 값을 설정해 그대로 표시합니다. 예) 롤러 둘레 200mm · 엔코더 2000펄스/회전이면 프리스케일 0.1 설정으로 0.1mm 단위 길이 표시 · 제어가 가능합니다.
Converts pulses into real length or position. e.g. a 200 mm roller with a 2,000 ppr encoder displays and controls in 0.1 mm steps with a prescale value of 0.1.
FEATURE 04
BATCH 카운터
Batch Counter
설정값 · 설정시간에 도달한 횟수를 별도로 집계합니다. 예) 상자당 사과 5개(설정값 5) 포장 시 완성된 상자 수(BATCH 값)를 동시에 계수 — 수량 관리와 생산 집계에 유용합니다.
Separately counts how many times the preset value or time is reached — e.g. counting finished boxes while counting 5 apples per box.
FEATURE 05
유연한 입출력 구성
Flexible I/O
NPN / PNP 입력을 스위치로 선택하고, 라인드라이버 입력 모델(L)도 지원합니다. 출력은 릴레이 접점(250VAC 2A)과 NPN 무접점을 함께 제공하며, 원샷출력 시간은 0.01~99.99초로 설정합니다.
Switch-selectable NPN/PNP inputs plus a line-driver model. Relay (250VAC 2A) and NPN outputs, with one-shot times of 0.01–99.99 s. NPN PNP LINE DRIVER RELAY
FEATURE 06
RS232 통신 · 현장 편의 기능
RS232 Output & Usability
계수값 · BATCH값 · 출력상태를 RS232(9600bps)로 전송해 상위 시스템에서 데이터를 수집할 수 있습니다. 듀얼 6-digit 표시(계수값 적색 / 설정값 녹색), 키 LOCK 스위치, DIN-Rail 원터치 장착으로 현장 사용성을 높였습니다.
Streams count, batch and output status over RS232 (9600 bps). Dual 6-digit display, key-lock switch and DIN-rail mounting for easy field use.

Technology · 엔코더 ×4 체배

ENC Mode · x4 Multiplication

엔코더 1펄스를, 4배 정밀하게

엔코더 A · B상 신호의 상승 · 하강 에지 4곳을 모두 계수하는 ×4 체배 방식입니다. 같은 엔코더로 4배의 분해능을 얻고, 두 신호의 위상차로 회전 방향까지 자동 판별합니다.

  • 분해능 4배 — 2000펄스 엔코더가 8000카운트/회전으로 동작합니다.
  • 방향 자동 판별 — CW 회전은 가산(+1), CCW 회전은 감산(−1)으로 계수합니다.
  • 100kcps 고속 응답 — ENC 모드에서 최소 신호폭 0.005ms까지 대응합니다.
  • ENC-1 / ENC-2 모드 — 회전 방향에 따른 가산 · 감산 방향을 선택할 수 있습니다.
