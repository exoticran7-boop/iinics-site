Rotary Encoder Series IA Series

인덕티브 로터리 엔코더

Inductive Absolute Rotary Encoder

전자기 유도 원리로 절대위치를 읽는 인덕티브 앱솔루트 엔코더. 광학부품이 없어 내구성이 뛰어나고, 외부 자기 간섭에 강해 오염 · 습기 환경에 특화되었습니다. 축이 돌출된 샤프트 타입 (IA50S · IA40S), 중심이 완전히 관통된 중공축 타입(IA40H), 한쪽이 막힌 빌트인 타입(IA40HB)의 3가지 외형으로 제공됩니다.

An inductive absolute encoder based on electromagnetic induction. No optical parts, strong immunity to external magnetic fields — built for contaminated and humid environments. Three housings: shaft, fully-open hollow and closed-end built-in.

Key Features · 제품 특징

FEATURE 01
앱솔루트 — 전원 인가 즉시 절대위치
Absolute Position Detection
각 회전각마다 고유한 코드를 출력하는 앱솔루트 방식입니다. 전원을 켜는 순간 현재 위치를 바로 알 수 있어 원점 복귀 동작이 필요 없고, 정전 후에도 위치를 잃지 않습니다.
Every angle outputs a unique code — the position is known the moment power is applied. No homing sequence, no position loss after a power interruption.
FEATURE 02
외부 자기 간섭에 강한 인덕티브
Immune to Magnetic Interference
전자기 유도 방식이라 모터 · 마그네트 척 등 강한 자기장 주변에서도 안정적으로 동작합니다. 광학부품이 없어 내구성이 뛰어나고 오염 · 습기 환경에 특화되었습니다.
Electromagnetic induction keeps readings stable next to motors and magnetic chucks. No optical parts — durable, and built for contaminated, humid environments.
FEATURE 03
Binary / Gray 코드 선택
Binary / Gray Code
출력 코드를 Binary와 Gray 중 선택합니다. Gray 코드는 하나의 비트만 변하면서 값이 바뀌기 때문에 비트 딜레이로 인한 순간 오독을 원천적으로 방지합니다. 회전방향(F: 시계 증가 / R: 반시계 증가)도 선택 가능합니다.
Gray code changes only one bit at a time, eliminating misreads from bit delays. Count direction is selectable (F: CW up / R: CCW up). BINARY GRAY F / R
FEATURE 04
2가지 출력 — 병렬 NPN / SSI
Parallel NPN / SSI Line Driver
병렬 NPN 모델은 2⁰~2⁹ 10개 신호선으로 분해능 8~1024를 직접 출력하고, SSI 모델은 라인드라이버 동기 시리얼 통신 (클럭 50k~500kHz)으로 최대 4096 분해능을 전송합니다.
Parallel NPN outputs 10 bit lines (res. 8–1024); SSI streams up to 4096 P/R over a synchronous line-driver interface at 50k–500 kHz.
FEATURE 05
SSI 멀티턴 — 16,384회전 카운트
16,384-Rev Multi-turn (SSI)
SSI 모델은 단회전 각도에 더해 회전수를 14bit(16,384회전)로 누적 카운트합니다. 긴 이송축 · 다회전 기구의 위치를 하나의 데이터로 관리할 수 있습니다. (전원 차단 시 다회전 카운트는 0으로 초기화됩니다.)
SSI adds a 14-bit revolution counter (16,384 turns) on top of the single-turn angle. Note: the multi-turn count resets to 0 at power off.
FEATURE 06
±1LSB 히스테리시스 · 장착 부속 동봉
±1 LSB Hysteresis · Kit Included
경계각에서의 값 떨림을 ±1LSB 히스테리시스로 억제합니다. 내충격 50G · 내진동 5G, 샤프트 타입은 커플링, 중공축 · 빌트인 타입은 브라켓이 동봉됩니다. 알루미늄 / PA66-GF30 바디, CE 인증.
±1 LSB hysteresis suppresses code flicker. 50G shock, 5G vibration. Coupling (shaft) or bracket (hollow/built-in) included. Aluminum or PA66-GF30 body. CE certified.

Technology · 감지 원리

Inductive Absolute Sensing

자기장 간섭 없이, 절대위치를 읽다

스테이터 코일이 만드는 고주파 자계를 회전하는 로터 패턴이 변조하고, 그 유도 신호로 현재 각도를 계산합니다. 자석이 아닌 유도 결합을 읽기 때문에 외부 자기장의 영향을 받지 않는 절대위치 검출이 가능합니다.

  • 전자기 유도 감지 — 코일과 로터 패턴의 유도 결합으로 각도를 읽는 완전 비접촉 방식입니다.
  • 외부 자기장 내성 — 영구자석을 쓰지 않아 모터 · 마그네트 척 옆에서도 안정 동작합니다.
  • 각도 = 고유 코드 — 최대 4096등분(12bit)의 각 위치가 서로 다른 코드로 출력됩니다.
  • SSI 멀티턴 — 회전수 14bit + 단회전 각도를 한 번의 시리얼 프레임으로 전송합니다.
